# MAX ↔ Telegram Bridge

Двусторонний мост между мессенджером **MAX** (web.max.ru / oneme.ru) и ботом **Telegram**.

- Входящие сообщения MAX → в тему (topic) супергруппы Telegram, **по одной теме на каждый MAX‑чат**.
- Ответ в теме Telegram → уходит обратно в соответствующий MAX‑чат.
- Полное управление через кнопки Telegram‑бота (только для админов привязанной группы).

> ⚠️ Использует неофициальный (reverse‑engineered) API MAX. Это нарушает условия MAX и создаёт риск блокировки аккаунта. Только для личного/образовательного использования. Никаких гарантий.

## Как это работает

- **MAX**: постоянное WebSocket‑соединение `wss://ws-api.oneme.ru/websocket` (JSON, ver 11). TLS‑хендшейк маскируется под Firefox (uTLS), т.к. edge/WAF MAX обслуживает только «браузерные» подключения. Авторизация — токен доступа (см. ниже). Соединение **всегда прямое**.
- **Telegram**: обычный Bot API (long‑polling `getUpdates`). Опционально весь трафик Telegram (и только он) идёт через SOCKS5‑прокси.
- **Токен MAX** берётся одним из двух способов:
  - из открытого браузера, залогиненного в web.max.ru, через Chrome DevTools Protocol (сервис сам запускает Edge/Chrome в режиме отладки);
  - через SMS‑авторизацию прямо из бота (без браузера).
- **Управление**: в личке боту (только админам группы) — кнопки: статус, перезапуск, SMS‑авторизация, логи, диагностика MAX.

## Требования

- Windows.
- Go 1.24+ (только для сборки).
- Телеграм‑бот (токен от [@BotFather](https://t.me/BotFather)).
- Супергруппа Telegram с включёнными **темами (topics)**; бот добавлен в неё **администратором**.
- Для захвата токена из браузера — установленный Edge или Chrome и один раз выполненный вход в web.max.ru (профиль запоминается). Либо SMS‑авторизация.

## Сборка

```
go build -o dist/maxtg.exe .
```

## Установка и запуск

1. Запусти `maxtg.exe` без аргументов — откроется консоль настройки.
2. Укажи телефон MAX, токен бота, при необходимости SOCKS5‑прокси для Telegram.
3. Получи токен MAX: пункт «Pull MAX token from browser» (откроется Edge — войди в web.max.ru один раз) **или** SMS‑авторизация.
4. Добавь бота в группу администратором и отправь в группе любое сообщение — ID группы определится автоматически.
5. Пункт «Install / update autostart» — бридж будет стартовать при входе в систему (обычное приложение в сессии пользователя, без службы и прав администратора).

Команды: `maxtg.exe console` (настройка), `maxtg.exe run` (запуск бриджа), `maxtg.exe install` / `uninstall` (авто­запуск).

## Управление через бота

В личке боту (для админов группы) — графическое меню: **Статус**, **Перезапустить**, **SMS Авторизация**, **Логи службы**, **Сырой лог (Debug)**, **Диагностика MAX**, **Тестовое сообщение**.

## Конфигурация (`config.json`)

Скопируй `config.example.json` в `config.json` и заполни. На Windows рабочий конфиг лежит в `%ProgramData%\MaxTgBridge\config.json`.

| Поле | Описание |
|------|----------|
| `max_ws_url` | WebSocket MAX (по умолчанию `wss://ws-api.oneme.ru/websocket`) |
| `phone` | Телефон MAX в формате `+7XXXXXXXXXX` (для SMS‑авторизации) |
| `telegram_bot_token` | Токен бота от @BotFather |
| `telegram_group_id` | ID супергруппы (`0` = определить автоматически) |
| `telegram_proxy` | SOCKS5‑прокси **только для Telegram** (пусто = напрямую), напр. `socks5://host:1080` или `socks5://user:pass@host:1080`. MAX всегда идёт напрямую. |
| `browser_cdp_url` | CDP‑endpoint браузера для захвата токена (по умолчанию `http://127.0.0.1:9222`) |
| `browser_match_url` | URL‑подстрока страницы MAX (по умолчанию `web.max.ru`) |
| `state_path` | Файл состояния (токен, deviceId, карта чат↔тема, offset) |
| `incoming_opcode` | Опкод входящих сообщений (`0` = дефолт `128`) |

Секреты (`config.json`, `state.json`) в репозиторий не попадают — они в `.gitignore`.
